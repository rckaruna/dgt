## Notes

* This package is a companion to: "Distributional Generalizability Theory: 
  Reliability for Non-Gaussian Measurements" (submitted to Psychometrika).

* Examples use \dontrun{} because they require fitted brms model objects,
  which take several minutes to compute. This is standard practice for 
  packages that depend on brms (see e.g., tidybayes, bayesplot).

* The package has been tested on R 4.3+ with brms 2.21+ on Ubuntu, macOS, 
  and Windows via GitHub Actions CI.
